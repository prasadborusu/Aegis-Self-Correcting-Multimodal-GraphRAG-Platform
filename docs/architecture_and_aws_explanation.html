Aegis — Self-Correcting Multimodal RAG Platform

An evidence-first knowledge intelligence platform built on AWS that mathematically audits factual claims, preserves document provenance, and autonomously executes secondary retrieval cycles when evidence is incomplete.

    FinalAnswer --> User

🔬 In-Depth Technical Approach & Mathematical Formulations

1

Structure-Aware Extraction

PyMuPDF layout analysis extracts heading hierarchies (H1-H3), line weights, tabular delimiters, and page bounds ($p \in [1, P]$), preserving logical document structure.

2

Deterministic Chunk Hashing

Chunks are partitioned along logical section boundaries and tagged with immutable metadata: $c_{\text{id}} = \text{UUID}(d_{\text{id}} \parallel p \parallel \text{idx})$.

3

Bedrock Titan v2 Embeddings

Generates 1024-dimensional normalized vectors ($\|\mathbf{v}\|_2 = 1$) via amazon.titan-embed-text-v2:0 for cosine proximity scoring.

4

Hybrid Retrieval Equation

Fuses semantic vector proximity with BM25 keyword matching to retrieve both conceptual topics and exact identifiers.

Score(c, q) = 0.70 · cos(v_q, v_c) + 0.30 · BM25(c, q)
5

Atomic Claim Decomposition

Answers are segmented into atomic claims $A = \{c_1, \dots, c_N\}$. Each claim is audited for lexical/semantic entailment against evidence chunks $\mathcal{E}$.

Grounding Coverage = (1/N) · Σ 𝟙(Confidence(c_i | E) >= 0.40)
6

Autonomous Self-Correction Gate

If Grounding Coverage < 75%, the query is reformulated to target missing entities ($q_{t+1} = \text{Reformulate}(q_t, \mathcal{U})$), executing Pass 2 retrieval.
